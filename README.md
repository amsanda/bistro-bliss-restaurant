## 📖 About the Project

Bistro Bliss Restaurant is a restaurant website built using HTML, CSS, and JavaScript.

The project aims to provide customers with an engaging online platform where they can discover the restaurant, browse its menu, view food and interior photography, learn about the restaurant, and submit reservation requests through WhatsApp.

The design follows a warm, elegant, and welcoming aesthetic, using neutral backgrounds, refined typography, and gold accents to reflect a premium yet comfortable dining atmosphere.

The website is designed with usability, accessibility, responsiveness, and customer convenience in mind.

## ✨ Features

### 🏠 Home Page
- Attractive hero section with restaurant imagery.
- Restaurant introduction and story.
- Food category previews.
- Featured menu items.
- Chef's special section.
- Gallery preview.
- Customer testimonials section.
- Reservation call-to-action.
- Footer with navigation and social links.

### 🍽️ Menu Page
- Categorized restaurant menu.
- Search functionality for menu items.
- Menu categories covering rice dishes, pasta, grills, pepper soups, local dishes, proteins, salads, beverages, and more.
- Clearly displayed dish names, descriptions, and prices.
- Food photography for selected categories.
- Interactive navigation between menu categories.

### 📅 Reservation Page
- Reservation form for customer details.
- Date and time selection.
- Guest selection.
- Occasion selection.
- Optional special requests.
- Basic form validation.
- WhatsApp integration for submitting reservation requests.

### 🖼️ Gallery Page
- Restaurant and food photography.
- Responsive image grid.
- Interactive image hover effects.
- Visual presentation of the restaurant's atmosphere and dishes.

### ℹ️ About Us Page
- Restaurant introduction and story.
- Dining philosophy and restaurant values.
- Restaurant experience highlights.
- Culinary presentation.
- Reservation call-to-action.

### 📞 Contact Page
- Dedicated contact page for restaurant visitors.
- Space for restaurant contact information and location details.

## 🛠️ Technologies Used

The project uses the following technologies and resources:

| Technology | Purpose |
|---|---|
| HTML5 | Website structure and content |
| CSS3 | Styling, layouts, animations, and responsive design |
| JavaScript | Interactive functionality and form handling |
| Google Fonts | Typography using Playfair Display and Poppins |
| Font Awesome | Icons and visual elements |
| Git | Version control |
| GitHub | Source code hosting |
| GitHub Pages | Static website deployment |
| WhatsApp | Reservation request submission |

**No frontend framework is required.** The website is built with vanilla HTML, CSS, and JavaScript.
